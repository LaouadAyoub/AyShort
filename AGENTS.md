# Repository working agreements

## Git naming

- Do not include "Codex" (in any capitalization) in branch names or commit messages.
- Name branches and commits after the actual change, using the repository's existing
  conventions, such as `fix/browser-tab-title` or `feat/copy-short-link`.
- Follow this naming preference for all work in this portfolio repository.

Frontend-specific guidance is in `frontend/AGENTS.md`.
